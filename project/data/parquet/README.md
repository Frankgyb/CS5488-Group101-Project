# parquet/ — not tracked

24 monthly TLC For-Hire Vehicle (FHVHV) files, `fhvhv_tripdata_2023-01.parquet` …
`fhvhv_tripdata_2024-12.parquet` (430–522 MB each, 11.6 GB total), are downloaded into this
folder. They are excluded from version control; this README keeps the folder visible in the
repository.

Rebuild:

    python project/code/download.py

See [`../README.md`](../README.md) for the complete tracked/untracked data map.
